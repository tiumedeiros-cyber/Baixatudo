# Story 3.1 — Conversas, respostas e opt-out (Fase 3)

**Status:** Ready for Review (testado com eventos simulados; webhook real depende do GOWA)
**Plano:** [docs/PLANO.md](../PLANO.md), Fase 3

## História

Como dono, quero ver as respostas dos leads classificadas, com uma sugestão de resposta pronta,
para fechar mais rápido sem perder ninguém nem incomodar quem pediu para sair.

## Critérios de aceite

- [x] **Webhook** do GOWA com assinatura HMAC-SHA256 (`X-Hub-Signature-256`); sem segredo ou com
  assinatura errada, recusa.
- [x] Resposta entra na conversa certa pelo telefone; o lead vai para *Respondeu* e os follow-ups pendentes são cancelados.
- [x] Classificação da resposta: interessado, preço, dúvida, sem interesse, "PARE", áudio, mídia e outro.
- [x] "PARE" (e variações como "para de me mandar mensagem"): número entra na lista de bloqueio,
  mensagens pendentes são canceladas e o lead sai do funil ativo.
- [x] Sugestão de resposta por intenção, que **você aprova** antes de sair (modo copiloto).
- [x] Recibos de entrega e leitura atualizam o status das mensagens.
- [x] Página **Conversas** (lista com não lidas, filtros) e conversa individual: histórico, resposta
  manual, assumir a conversa (humano), marcar como lida, bloquear.
- [x] Detalhe do lead com link para a conversa; contadores de Fila e Conversas na barra lateral.
- [x] No modo demonstração dá para simular uma resposta recebida (para ver o fluxo sem WhatsApp).

## Qualidade

- Testes do classificador (frases reais de lead), da assinatura, do parser do webhook e do motor.
- Nenhuma mensagem foi enviada; o webhook nunca foi chamado pelo GOWA real.

## Pendências (dependem de você)

- [ ] Subir o GOWA por `npm run gowa` (ele registra o webhook com a assinatura correta)
- [ ] Mandar uma mensagem de outro número para o chip e ver se aparece em Conversas
- [ ] Conferir se o seu GOWA entrega o evento com o mesmo formato (versões diferentes variam)

## Limitações conhecidas

- A classificação é por regras em português; o que não bate com nenhuma regra cai em "outro" para você decidir.
- Áudio não é transcrito: aparece como "áudio" e pede resposta sua.
- Não há IA gerando a resposta; as sugestões vêm de modelos por intenção.
