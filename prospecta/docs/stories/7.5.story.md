# Story 7.5 — Aposentar o número original (JK 01) sem reconectar a mesma instância

**Status:** Ready for Review (tipos e lint limpos; testes de números verdes). O JK 01 já foi aposentado no banco real.

## O pedido

"Remove esse (JK 01) para eu não reconectar na mesma instância; isso evita ban."

## O que bloqueava

O painel proibia aposentar o número original (`legacy`): o botão não aparecia e `retireAccount` recusava. O motivo era o modo de
"um número só": ele usa o aparelho padrão do GOWA e o estado de envio guardado nas Configurações. Aposentar o original sem mexer
nisso deixaria o painel nesse modo com um único número novo e o envio sairia pelo aparelho padrão, não pelo aparelho do número.

## O que mudou no código

- [x] `roster.ts`: "um número só" passa a ser **só o original ativo sozinho** (ou nenhum cadastrado). Qualquer outro caso é o modo de
  vários números, com cada número no próprio aparelho: mais de um ativo, um único ativo que não é o original, ou todos aposentados
  (nada envia).
- [x] `numbers.ts`: `retireAccount` vale também para o original. Cancela rascunhos e aprovadas que não saíram, solta o aparelho e
  marca como aposentado. **Nada é apagado**: conversas e mensagens ficam.
- [x] `numeros-actions.ts`: o "fixar o aparelho do original" ignora o original aposentado (senão ele seria religado a um aparelho
  qualquer ao adicionar um número).
- [x] `number-card.tsx`: "Aposentar este número" aparece também no original (dentro de Ajustes, com confirmação).
- [x] `numeros/page.tsx`: texto para "nenhum número ativo" e para "um número ativo que não é o original".
- [x] Testes: aposentar o original (cancela, solta o aparelho, mantém as conversas), elenco sem o original (um número novo sozinho já
  é vários números e vira o padrão) e volta do worker sem números ativos (não envia).

  voltam para "Leads liberados" na Fila (36 liberados agora).

  automação continua **pausada**.

canceladas pela Fila (**Reabrir**). Mas o JK 01 não tem mais aparelho no GOWA.

## Para adicionar o próximo número

Números → **Adicionar número**. Ele cria um aparelho novo no GOWA (id novo), nasce pausado, e só você libera o envio.
