# Story 1.1 — Caçador de leads e funil (Fase 1)

**Status:** Ready for Review (busca real no Apify testada em 2026-10-22; faltam só as escritas do Supabase com sessão real)
**Plano:** [docs/PLANO.md](../PLANO.md), Fase 1

## História

Como dono, quero escolher cidade e nicho e receber uma lista de negócios sem site, ranqueada, para
decidir quem entra na fila de abordagem.

## Critérios de aceite

- [x] Caçador: nicho + cidade + UF + quantidade; custo estimado antes de buscar; teto de custo por busca.
- [x] Busca no Google Maps via Apify, em duas etapas (iniciar, acompanhar) sem travar a tela.
- [x] Importação de JSON (array, objeto com `items`/`results`/… ou um item por linha).
- [x] Deduplicação por `placeId` e por celular, dentro do lote e contra a base.
- [x] Telefone normalizado para E.164; celular x fixo; DDD validado.
- [x] Site classificado: sem site, só rede social (Instagram conta como sem site), fraco, próprio.
- [x] Análise de site sob demanda (HTTPS, celular, conteúdo, ano antigo), com proteção contra SSRF.
- [x] Nota de 0 a 100 com explicação por critério; fechado/bloqueado = 0.
- [x] Elegibilidade (celular, aberto, sem opt-out) com o motivo quando falha.
- [x] Lista com filtros (site, etapa, elegibilidade, nota mínima, texto, ordem) e paginação na URL.
- [x] Seleção em lote: aprovar para a fila (Qualificado) e descartar (Perdido).
- [x] Funil kanban com arrastar e soltar, otimista, com reversão em caso de erro.
- [x] Detalhe do lead: nota explicada, dados, anotações, etapa, histórico.
- [x] Comando: KPIs, funil, atividade recente, buscas, status da automação.
- [x] Configurações: oferta, ticket médio (R$ 800), teto do Apify, nichos de ticket alto.

## Limitações conhecidas

- A busca de texto usa `ilike` no Supabase: não ignora acento (na demonstração ignora).
- O funil mostra os 60 melhores por coluna; o restante aparece como "+N fora desta vista" (use o Caçador).
- Verificação de WhatsApp (`whatsappStatus`) fica `unknown` até a Fase 2.
- O JSON do site antigo só entra se for a exportação original do Apify (os leads dele ficam no navegador).
